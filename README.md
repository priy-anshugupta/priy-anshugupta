## 🧠 About Me

<img align="right" width="280" src="https://media.giphy.com/media/qgQUggAC3Pfv687qPC/giphy.gif"/>

I'm a **3rd-year AI/ML engineer** at Vidyalankar Institute of Technology, Mumbai, focused on building **production-grade agentic AI systems** — from GraphRAG pipelines to multi-agent orchestration frameworks. My work sits at the intersection of **LLM engineering** and **full-stack product development**, with a strong emphasis on shipping systems that are explainable, secure, and genuinely useful, not just impressive demos.

| **Impact** | Kaggle AI Agents Intensive (Google) capstone submission — Concierge Agents track |

<details>
<summary><b>🩻 Code MRI — AI-Powered Open Source Onboarding Engine</b></summary>
<br/>

An intelligent static analysis platform that gives any public GitHub repository an automated "health check" — code structure visualization, quality scoring, and an interactive RAG-based chat interface — without ever executing the target code, aimed at cutting new-contributor onboarding time from hours to minutes.

| | |
|---|---|
| **Stack** | FastAPI, Next.js 14, TypeScript, LangChain, FAISS, Gemini 2.5 Flash, Radon, SQLite |
| **Scale** | Handles repos up to 100MB / 10,000 files with parallel analysis pipeline |
| **Performance** | Sub-30s analysis for small-to-medium repos, sub-3s RAG chat responses |
| **Security** | Sandboxed shallow clones, disabled git hooks, secret scanning, rate limiting |
| **Impact** | Static-analysis-first approach eliminates code execution risk during exploration |
| **Repository** | [github.com/priy-anshugupta/Code-MRI](https://github.com/priy-anshugupta/Code-MRI) |

</details>
